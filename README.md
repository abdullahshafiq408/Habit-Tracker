# Habit Tracker

A lightweight, frontend-only habit tracker built to keep things simple. It tracks daily habits on a weekly grid, calculates current streaks, and saves everything directly to the browser.

## Tech Stack
* Vanilla HTML5
* Vanilla CSS3
* Vanilla JavaScript

## How to run locally
Because this is built with pure vanilla web technologies, there's no complicated setup or build step. 

1. Clone or download this repository.
2. Navigate to the project folder.
3. Simply double-click `index.html` to open it in your default web browser.

Everything runs locally, and your habit data is saved automatically to your browser's `localStorage`.
