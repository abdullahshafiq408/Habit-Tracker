# Habit Tracker

A lightweight, frontend-only habit tracker built to keep things simple. It tracks daily habits on a weekly grid, calculates current streaks, and saves everything directly to the browser.

**Live Demo:** [(https://abdullahshafiq408.github.io/Habit-Tracker/)]

## Tech Stack
* Vanilla HTML5
* Vanilla CSS3
* Vanilla JavaScript

## How to Run

### Option 1: View Live (Recommended)
No installation or build steps are required. Just click the live demo link above to test the app instantly in your browser. 

### Option 2: Run Locally
Because this is built with pure vanilla web technologies, there's no complicated setup or server required. 

1. Clone or download this repository.
2. Navigate to the project folder.
3. Simply double-click `index.html` to open it in your default web browser.

Everything runs locally, and your habit data is saved automatically to your browser's `localStorage`.
